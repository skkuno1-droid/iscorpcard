# 법인카드 집근처 분석

법인카드 사용내역 엑셀 + 직원 집 주소 → 카카오 지도 좌표 → 집 반경 내 사용 · 주말/공휴일 · 심야 · 민감업종 · 반복사용으로 우선 검토 건 선별.

## 실행
1. `실행.bat` 더블클릭 (Python 필요). 브라우저가 `http://localhost:8080` 으로 열립니다. `index.html` 을 직접 열면(file://) 카카오 지도가 동작하지 않습니다.
2. **카카오맵 연결**: developers.kakao.com › 내 애플리케이션 › 앱 키 › *JavaScript 키* 입력.
   플랫폼 › Web 도메인에 `http://localhost:8080` 등록, 제품 설정에서 카카오맵 사용 ON.
3. 법인카드 엑셀(.xlsx/.xls/.csv) 올리기 — 회사 표준 18개 열 자동 인식.
4. 직원 집 주소 입력(또는 주소록 양식 내려받아 채워 올리기) → **분석 시작**.
5. 결과 엑셀로 내보내기(거래별 거리·등급·좌표 포함).

처음 써보려면 **가상 샘플 데이터로 체험** (지도 없이도 표·판정 확인 가능, 지도는 키 연결 시).

## 판정 기준 (화면 우측에도 표시, 설정에서 변경 가능)
거리 30~55점 + 주말/공휴일 20 + 심야 15 + 민감업종 10 + 같은 가맹점 3회↑ 10, 근무지 인근 −25, 위치가 동·도로 단위면 −10.
65↑ 고위험 / 45↑ 주의 / 그 외 낮음. 온라인(PG)·택시·해외·취소는 위치 분석에서 제외.

## 알아둘 점
- 카드 내역·집 주소는 서버로 보내지 않고 브라우저에서만 처리. 카카오 API에는 주소 문자열만 전송. 가맹점 좌표만 브라우저에 캐시(집 주소는 저장 안 함).
- DRM 걸린 엑셀(파일 시작이 `SCDSA`)은 읽을 수 없습니다 — DRM 해제본을 쓰세요.
- 위험 점수는 선별용 참고치이며 위반 판정이 아닙니다. 공휴일 목록은 2024~2026년 기준이니 매년 갱신하세요.
- 엑셀 라이브러리(SheetJS)·Pretendard 글꼴은 CDN에서 불러옵니다(사내망에서 막히면 내려받아 같은 폴더에 두고 경로 수정).

## AI 이상징후 요약 · 경영진 보고서 (Gemini)
1. Google AI Studio(aistudio.google.com) › Get API key 로 키 발급 → 화면의 **Gemini 연결**에 입력 후 *연결 테스트*. 모델명은 직접 바꿀 수 있습니다(기본 `gemini-3.8-flash`).
2. 분석을 끝낸 뒤 **AI 이상징후 요약 › 요약 생성**, **경영진 보고서 작성기 › 보고서 초안 생성**.
3. 생성 전에 **Google로 전송될 내용**이 확인 창에 뜹니다. 승인해야만 전송됩니다.

전송 범위: 지표 · 이용자별 통계 · 위험 상위 거래 15건 · 휴일 고액 거래 10건(가맹점명·업종·금액·일시·근거 태그).
전송하지 않음: 카드번호 · 사업자번호 · 승인번호 · 집/근무지 주소와 좌표. 이용자명은 기본 가명(이용자 A…)으로 보내고 결과에서 원래 이름으로 되돌립니다.

보고서: 지표 표 · 이용자별 표 · 상위 거래 목록은 앱이 계산한 값이고, 해석 문장만 AI가 씁니다. 화면에서 직접 고친 뒤 HTML 다운로드 / 인쇄(PDF 저장) / 복사(Word 붙여넣기)가 가능합니다.

주의: API 키는 비밀값입니다. 기본은 이 탭을 닫으면 사라지고, "이 브라우저에 키 저장"을 켰을 때만 PC에 남습니다(공용 PC에서는 켜지 마세요). 외부 AI 서비스 사용이 회사 보안 규정에 맞는지 먼저 확인하세요. AI 문장은 초안이며 위반 판정이 아닙니다.
